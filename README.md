# MusicCube promos

Pictures in this repo show up inside the MusicCube app. No app update needed.

| File name | Where it shows |
|---|---|
| `home-banner.jpg` | Slim banner at the top of Home (wide picture, about 3:1, e.g. 1200×400) |
| `home-card.jpg` | Big card between the Home shelves (about 16:9, e.g. 1280×720) |
| `now-playing.jpg` | A slide in the Now Playing slideshow (square, e.g. 1080×1080) |
| `link.txt` | Optional. One web address; tapping any promo opens it |

- `.png` and `.webp` work too (`home-banner.png` etc.).
- **To show a promo:** Add file → Upload files → drop the picture with the right name → Commit.
- **To stop it:** open the file → ⋯ → Delete file → Commit.
- **To change it:** upload a new picture with the same name.
- Phones pick up changes the next time the app opens (checks at most every 3 hours).
- Music never stops for a promo. Nothing shows in Android Auto.
